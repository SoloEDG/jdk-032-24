# 骨牌造境

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。

## 对照回看

每次模拟的结果会自动留存（最多 12 份）。在「对照回看」面板里挑两份结果，
即可并排比较两条触点轨迹：共同触点按（来源牌 → 接收牌 @ 接触边 + 第几次发生）
对齐，选中共同触点时两路各自跳到自己的事件时刻；两路时间轴互不影响。

## 验证

```sh
npm run verify:compare
```

用两份构造布局校验对照逻辑：一份在枢纽中断，另一份多倒三枚后才停止；
另覆盖事件数不同不按行号对齐、同一对牌碰两次不合并、触点相同时刻不同等情形。
